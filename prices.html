Chapter 00 — market data

What the chains are worth today

Pulled live from the CoinGecko public API — no key, no backend, no account. Each card shows the current price, the last 24 hours of movement and a 7-day trend line. Switch currency, add any coin CoinGecko lists, or let the board refresh itself every minute.

Worth being precise about

This page is not reading a blockchain. CoinGecko is an ordinary web API — a company’s price database. Prices are what people pay for these assets, which is market data, not chain data. The rest of this site is about the chain itself.
